# Som — обновления

Отсюда Som сам скачивает новые версии. Руками здесь ничего делать не нужно.

- `latest.json` — какая версия последняя, что в ней нового и контрольные суммы SHA-256 всех файлов;
- `v/<версия>/` — файлы программы (папка `resources/app`) этой версии.

Som раз в 6 часов читает `latest.json`, скачивает файлы новой версии, сверяет суммы и предлагает перезапуститься.
Если новая версия не запускается, Som возвращается к предыдущей.

Кто может менять этот репозиторий, тот может выполнить свой код у всех, кто пользуется Som, — держите на аккаунте двухфакторную защиту.
